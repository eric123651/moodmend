## 项目结构说明

### 依赖管理

- 项目使用单一的 `requirements.txt` 文件（位于根目录）
- 所有依赖都指定了明确的版本号，确保环境一致性
- 阿里云SDK统一使用 `alibabacloud-*` 命名空间的新版SDK

### PWA配置管理

- 项目使用单一的 `manifest.json` 配置文件（位于根目录）
- 主题色为粉色系 (`#FF69B4`)，符合应用的视觉设计要求
- 所有路径引用确保在各种部署环境下正常工作

### 资源文件优化

- 图标文件集中存储在根目录 `icons/` 文件夹
- 前端通过符号链接访问图标资源，避免文件冗余
- 符号链接路径：`src/frontend/icons` → `../../icons`

## 开发环境搭建

### 安装依赖

```bash
# 开发环境
pip install -r requirements.txt

# 后端生产环境
cd src/backend
pip install -r requirements.txt
```

### 运行后端服务

```bash
cd src/backend
python moodmend_backend.py
```

### 访问前端界面

在浏览器中打开：
- 主页面：`src/frontend/moodmend_ui_demo.html`

## 项目功能概述

MoodMend 是一个情绪管理应用，帮助用户：
- 记录和管理日常情绪状态
- 通过语音识别输入情绪记录
- 基于AI分析提供情绪调整建议
- 查看情绪历史趋势

## 技术栈

- **前端**：HTML, JavaScript, IndexedDB
- **后端**：Python Flask
- **云服务**：阿里云NLP、语音识别、通义千问API
- **数据库**：SQLite (后端), IndexedDB (前端)

## 注意事项

- 确保配置正确的阿里云API密钥
- 开发前请安装所有必要的依赖
- 前端图标引用通过符号链接实现，不要直接删除或修改链接
